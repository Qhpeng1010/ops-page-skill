# 交互与验收规则

这是平台交互和验收规则的唯一维护入口。页面族行为放在 `page-patterns/`，Ant API 放在 `references/antd-components.md`；`CUSTOMIZE.md` 只做定位索引。

- **INT-01 REQUIRED**：关键动作定义触发、前置条件、处理中、成功、失败与恢复。查询影响数据，导出生成文件，保存更新结果。
- **INT-02 REQUIRED**：加载、无结果、请求失败、无权限分别表达。错误可重试；局部失败保留其他内容；纯静态页无需强加异步流程。
- **INT-03 DEFAULT**：提交式查询区分输入草稿和生效条件；查询/重置回第一页，分页保留条件。实时过滤按需求决定，不叠加冲突机制。
- **INT-04 REQUIRED**：Form 校验错误贴近字段，失败保留输入；提交防重复；关闭未保存内容有处理。只在丢失内容有影响时确认。
- **INT-05 REQUIRED**：危险操作说明对象与影响并使用 danger；隐藏按钮不等于后端鉴权。幂等和权限按真实接口约定，不虚构保证。
- **INT-06 REQUIRED**：搜索和联动防旧响应覆盖新响应；加载状态可见，成功同步列表、详情和可用动作。
- **INT-07 DEFAULT**：普通成功用 message，持续性区域问题用 Alert，需要决策用 Modal/Result；用 App.useApp() 获取主题内反馈。
- **INT-08 REQUIRED**：字段有 label，图标按钮有 aria-label，状态有文字，保留弹层焦点与 Escape。自定义组件也可键盘操作。
- **INT-09 REQUIRED**：无接口时在 `page-spec.json` 和 `review.md` 中记录数据模式、演示范围、未接入能力及持久化范围；上传不发往猜测地址，本地文件选择与真正上传的边界也记录于此。页面内默认不添加“本地演示数据”“未接后端”“仅当前页面有效”“刷新恢复示例”等实现说明，包括 Alert、横幅、副描述或弹窗；仅用户明确要求此类提示时显示。查询失败、字段校验、操作结果等业务反馈仍按对应交互规则实现。
- **INT-10 REQUIRED**：验收只写实际证据；类型检查不等于视觉通过，本地演示不等于后端联调，未执行项明确标记。
- **INT-11 DEFAULT**：弹窗默认点击遮罩关闭，只有用户明确要求时才禁止；表单弹窗、提示与确认弹窗均遵循此规则。遮罩关闭走取消逻辑，不触发保存或确认；未保存内容处理与取消按钮一致。

- **INT-12 DEFAULT**：Drawer 标题左对齐、关闭按钮固定右侧；footer 始终右对齐，辅助按钮在左、主按钮在最右。只读详情默认提供右侧辅助“关闭”按钮。
- **INT-13 DEFAULT**：Modal 标题下方和底部操作区上方各有 1px 通栏灰线，线两侧各留 `layout.modalDividerGap`（16px）；弹窗标题不自动增加副描述、引导段落或示例说明。
- **INT-14 DEFAULT**：Modal / Drawer 内表单字段保持 16px 间距；网格字段清零 Form.Item 自带下边距，避免与网格 gap 叠加。
- **INT-15 REQUIRED**：表格横向溢出时操作列固定在右侧；刷新、密度、列设置和业务操作必须有可见行为，不能只提供静态装饰。
- **INT-16 REQUIRED**：验收分为契约、类型、构建和人工视觉 / 交互检查；类型检查或构建通过不代表视觉验收通过，未执行项必须明确记录。
- **INT-17 REQUIRED**：列表行操作需要二次确认时，使用 `App.useApp().modal.confirm(withModalDividers(...))` 的 Modal 提示形态：保留黄色警示图标，标题、正文和底部操作区使用统一 Modal 分隔线，操作按钮位于右下角；危险操作的确认按钮使用 danger。不要改用普通受控 `Modal` 或 `Popconfirm`。取消、点击遮罩或按 Escape 只关闭弹窗，确认后才执行操作。

常规验收覆盖主路径、空结果与失败恢复；编辑类补充无效输入与取消，框架类补充切换/关闭/刷新/窄屏。只为复杂逻辑和重要回归编写必要测试。
