# 详情页建议

对象身份与状态 → Descriptions 分组 → 关联记录/Timeline → 业务操作。只读字段不用禁用 Input 冒充。

详情抽屉及同一内容容器内的分组用灰线分隔，分割线上下各留 `layout.elementGap`（默认 16px）；复用 `.page-stack` 与相邻 `.platform-detail-section`，确保弹层内间距生效。灰线只放在相邻模块之间，不放在模块标题下；不要在模块标题和内容之间手动插入 `Divider`。具体间距组成与验收见 [模块页规则](module-page.md)。

详情使用 Drawer 时统一加 `platform-detail-overlay` 语义类。Drawer 内容区四边使用 Ant 默认 `24px` body padding；详情分组标题到自身内容的间距为 `layout.detailTitleGap`（默认 12px）。Modal 沿用现有标题分割线、正文留白和底部操作区标准。该间距规则与分组之间的 `16px → 灰线 → 16px` 分隔规则相互独立。

状态影响可用动作；不存在、无权限和加载失败有不同表现。上下文详情可用 Drawer；长任务或独立分享使用页面。Drawer 标题栏默认标题左对齐、关闭按钮固定右侧，使用 Ant `closable={{ placement: 'end' }}`；footer 按钮始终右对齐，多个操作按辅助在左、主按钮在最右排列；只读详情在底部提供右侧辅助按钮“关闭”，编辑 / 提交型详情按业务增加操作；返回保留来源筛选和分页。

明确要求在新标签页查看详情时采用 [模块页规则](module-page.md)：灰色背景、四周 12px 留白，白色模块承载信息；单模块撑满可用区，多模块按内容自然增高。默认不添加标题副描述。列表到隐藏详情页的对象 ID 必须可恢复，至少使用路由参数、可恢复页面状态或页面约定的 sessionStorage；刷新后应继续展示原对象，只有确实没有绑定 ID 时才显示空状态。多模块页中使用 `PlatformModuleDescriptions`：默认三列、行间距 12px；详情模块之间使用灰色分割线，模块标题下不重复放线。关联表格默认无独立表格标题和刷新 / 密度 / 列设置，含表格的模块关闭标题分割线，具体实现见模块页规则。
