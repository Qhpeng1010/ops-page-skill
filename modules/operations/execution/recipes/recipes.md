# 可组合页面配方

配方用于复用稳定的页面结构和交互，不是固定模板，也不限制业务字段。分发器根据自然语言中的任务、对象、字段清单、动作和载体偏好返回多个可组合配方；生成时保留用户原始字段和特殊要求。

- **管理列表**：查询、表格、工具栏和分页。只要需求表达查找或管理一组记录，或提供“条件 / 表格字段 / 列”等结构化字段清单，即可命中，不要求固定页面名称。
- **表单弹窗**：新增、创建、编辑、录入等短任务默认使用 Modal；用户明确指定 Drawer 或新标签页时，显式载体优先。
- **详情抽屉**：列表中的查看、详情、明细等上下文任务默认使用 Drawer；用户明确要求弹窗或独立页时服从需求。
- **业务标签页**：新增、编辑、详情等任务明确需要新页面、独立页、工作区页签或保留独立地址时使用 React 模式，通过 PlatformShell 注册页面。
- **行操作确认**：禁用、启用、删除、下线、作废等操作按影响添加 `modal.confirm`，通过 `withModalDividers` 使用统一 Modal 提示形态；危险操作确认按钮使用 danger。
- **批量工具**：批量、导出、勾选和选中项等语义命中列表工具栏，可组合导出或批量处理。
- **多模块工作区**：多模块、关联信息、信息分组等语义命中 React 多模块页面；模块按业务关系组合，不按字段数量机械拆分。

配方可以组合，例如“代理商列表 + 新增弹窗 + 详情抽屉 + 启用/禁用确认”。匹配结果是生成建议；如果自然语言提出额外字段、不同载体或新的交互，直接扩展或覆盖对应配方，不因注册表缺少某个字段或词语而拒绝命中。

语义匹配优先看任务关系，不要求业务对象使用固定名称：提供“条件、表格字段、table值、列、筛选”等结构信息即可命中列表配方；出现“查看 / 明细 / 详情”即可命中详情配方；出现“新增 / 创建 / 编辑 / 录入”即可命中表单配方；出现“独立页 / 新标签页 / 工作区 / 页签”即可命中新标签页配方。命中多个配方时组合实现，用户明确指定 Modal、Drawer 或新标签页时覆盖默认载体。
