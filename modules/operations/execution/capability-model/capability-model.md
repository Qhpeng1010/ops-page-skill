# 开放能力模型

参考 YiPex 的 Skeleton / Region / Capability / Binding 分层，但不复制它的固定渲染引擎。

1. Skeleton：主要任务结构，例如查询工作台、对象编辑或开放工作台。
2. Region：筛选、表格、指标、详情、编辑、画布等区域。
3. Capability：具体行为，包含输入、输出、状态、依赖和验收。
4. Binding：区域/页面间传递的 ID、筛选条件、选中项和结果。

目录仅帮助发现可复用的设计与代码。默认开放生成；未登记能力照常实现，不修改需求以命中模板。多个区域可以组合，新结构使用 custom。

## 状态

- guidance：有实现指引，仍需生成代码。
- example：模板里有可运行演示；不等于任意业务的通用实现或后端已接入。
- extension：需要根据任务选择专业实现或额外依赖。

新增能力时写清：自然语言任务、区域、Ant 组件或扩展依据、输入、成功结果、失败恢复和验证路径。先在当前页完成，复用稳定后再登记。修改能力目录不自动给历史页面增加功能。
