# 运营后台页面域

服务运营、管理、查询、配置、审核和分析任务。业务名称与字段随需求，商户查询仅为可运行示例。

- 标准 UI 统一使用 React Ant Design，包括菜单、页签和所有操作控件。
- Shell 位置关系参照用户截图，布局由本地代码掌握，不依赖 ProLayout、Umi 或整套后台框架。
- 不绑定 YiPex 品牌或商户业务；参考的是分层组织和开放能力思路。
- 默认中文；日期、币种、单位、时区和精度沿用项目与需求。未提供时记录假设，不从演示数据推断规则。
- 原型可使用本地数据；真实接口沿用项目适配层。两者分开验收。

共享样式数值以 [platform.config.json](platform.config.json) 为源，共享框架行为以 [shell-contract.md](shell/shell-contract.md) 为源。单页例外只影响当前任务，除非用户要求修改平台。
